# 🚀 速算小达人 · 三年级速算练习

帮助小学三年级学生练习速算的小游戏，纯静态实现，零依赖，双击即玩。

> 👶 本项目还包含给中班小朋友（4~5 岁）的姊妹版「数数小达人」，入口在 `kids.html`（首页底部有互链）。

## 在线体验

已通过 GitHub Pages 部署：<https://xwang9401.github.io/math-game/>

## 运行方式

```powershell
start .\index.html
```

或直接在文件管理器中双击 `index.html`，用浏览器打开。

## 游戏内容

| 题型 | 基础难度 | 进阶难度 |
|------|----------|----------|
| 加法 | 100 以内（和 ≤ 100） | 1000 以内 |
| 减法 | 100 以内（差 ≥ 0） | 1000 以内（差 ≥ 10） |
| 乘法 | 表内乘法（2~9 × 2~9） | 整十数 × 一位数、两位数 × 一位数 |
| 除法 | 两位数 ÷ 一位数，以整除为主 | 同左，商可到两位数，带余数更多样 |

- 除法除数恒为一位数（2~9），约 85% 整除、约 15% 带余数（如 37 ÷ 5 = 7 余 2）
- 带余数的除法按「商 余 数」分别填写两个框

## 游戏模式

- **闯关冒险**：雪儿公主的魔法之旅（原创冰雪公主形象）——3 个世界共 12 关（魔法花园 → 冰晶雪山 → 梦幻城堡），每关一场追逐战：答对一题公主向终点前进一步，时间流逝和答错都会让身后的怪兽逼近，公主到达终点水晶即通关，被追上则失败。普通关答对 75% 可过关；Boss 关怪兽更快。按正确率评 1~3 星，每关收集一颗水晶碎片，集齐 12 颗解锁大结局。进度自动保存
- **速算秘籍（上卷 · 速算技巧）**：8 张秘籍卡按「入门 → 进阶 → 高手」顺序解锁，每张分三步——**学**（口诀 + 例题分步演示，点「下一步」逐步展开）、**演练**（5 道定向练习，答错时展示这道题的分步提示，可点 ✓ 提前继续）、**掌握考验**（8 题每题限时 15 秒，答对 ≥7 通过）：
  - 🤝 凑十与凑整：见 9 想 1、见 8 想 2；连加先凑整（25+38+75）
  - 🪄 减法性质：连减两个数 = 减去它们的和（250−37−63）
  - 🎯 接近整百：先看成整百算，多退少补（298+456、502−197）
  - ⚡ ×5 与 ×25：折半乘十、除四乘百（36×5、48×25）
  - ✨ ×99 与 ×101：分配律（34×99 = 3400−34）
  - 🔮 ×11 秘技：两边一拉，中间相加，满十进一
  - 💞 头同尾合十：头×(头+1) 拼上 尾×尾（23×27 = 6|21 → 621）
  - 📿 高斯求和：(首+尾)×项数÷2
  - 星级：完成演练 = 1 星；考验通过 = 2 星；全对 = 3 星。全部掌握获「👑 速算大师」称号。进度保存在 `sxd_scrolls`，与闯关存档一样做连续性校验
- **练习模式**：自选题型（加法/减法/乘法/除法，可多选），不限时，答完即时反馈
- **挑战模式**：限时 60 秒，四种题型混合出题；连对连击加分（基础 10 分，连击每 +1 多 2 分），答错连击清零；结束展示得分、正确率、最高连击，破纪录自动保存

## 趣味特效

- 答对喷彩带雪花、连对 ≥6 触发冰晶风暴，答对音调随连击上行
- 怪兽逼近时跑道泛红光 + 心跳音效
- 累计答对每满 50 题、三星过关、通关都会全屏「冰晶绽放」庆祝
- 过关星星逐颗弹出动画

## 👶 幼儿版：数数小达人（kids.html）

给中班小朋友（4~5 岁）的数学启蒙姊妹版，与大孩子版**同仓库、同部署、互相独立**（`game.js` 与 `kids.js` 互不引用，仅共用 Service Worker、图标和部署）。访问 `/kids.html` 或从大孩子版首页底部链接进入。

与大孩子版的核心差异：

- **不依赖识字**：题目用实物图案展示（🍎🍎 + 🍎），浏览器语音读题（`speechSynthesis`，不支持时自动静默），点题目文字或 🔈 可重听
- **点选作答**：3 个大数字泡泡或图案堆点选，不需要键盘输入
- **零压力**：没有怪兽、没有倒计时；答错轻轻提示后可无限重试，错误选项会灰掉引导继续
- **数一数**支持「点一个数一个」：点图案会标上数字角标并朗读计数

六个活动按顺序解锁（每轮 5 题，一次全对得 3 星）：

| 活动 | 内容 |
|------|------|
| 🍎 数一数 | 3~10 个实物，点一个数一个 |
| 🔢 认数字 | 实物↔数字双向配对（1~10） |
| ⚖️ 比多少 | 两堆实物哪边多 |
| ➕ 小加法 | 5 以内实物合并 |
| ➖ 小减法 | 5 以内「吃掉几个还剩几个」（含剩 0） |
| 🌟 大冒险 | 10 以内加减混合（前面都玩过后解锁） |

引导角色是「小星公主」（雪儿公主的妹妹，原创形象）。进度存 `sxd_kids_stars`（带连续性校验）；与大孩子版共享音效开关偏好（`sxd_sound`）。独立的 `manifest-kids.json`，可单独添加到主屏幕。

## 操作

- 点击屏幕数字键盘输入；也支持物理键盘（数字键、Backspace 退格、Enter 确定）
- 带余数的除法：商框输入两位后自动跳到余数框，也可点「填写余数 →」按钮或直接点余数框
- 右上角可切换基础/进阶难度、开关音效（Web Audio 合成，无外部资源）

## 数据保存

- 挑战模式历史最佳按难度分别保存在浏览器 localStorage（`sxd_best_basic` / `sxd_best_advanced`）
- 闯关进度（各关星星数）保存在 `sxd_adventure`，速算秘籍星级保存在 `sxd_scrolls`，幼儿版活动星级保存在 `sxd_kids_stars`，累计答对题数保存在 `sxd_total`
- 音效偏好保存在 `sxd_sound`（大小两个版本共享）

## 在平板 / 手机上玩（PWA）

游戏是触屏优先设计，已支持 PWA（`manifest.json` + `sw.js` + 图标）：

1. 把游戏部署到任意 HTTP 地址（局域网服务器或托管平台，见下文）
2. iPad/iPhone 用 Safari 打开页面 → 点分享按钮 → 「添加到主屏幕」
3. 之后从主屏幕图标打开，全屏无地址栏，像 App 一样用，断网也能玩（Service Worker 缓存）

> 注意：Service Worker 只在 http/https 下生效，直接用 `file://` 双击打开时自动跳过注册。

## 发布方式

**局域网试玩（最快）**：在 `math-game` 目录执行 `python -m http.server 8000`（或 `npx serve -l 8000`），iPad 连同一 Wi-Fi，访问 `http://电脑IP:8000`（IP 用 `ipconfig` 查询）。

**免费静态托管**：Netlify Drop（拖拽文件夹）、Vercel、GitHub Pages、Gitee Pages（需实名）、腾讯云 COS / 阿里云 OSS（开启静态网站托管）。面向国内用户建议后两者。

## 自定义

想调整游戏参数，改 `game.js` 顶部的 `CONFIG`：

| 配置项 | 含义 |
|--------|------|
| `challengeSeconds` | 挑战模式时长（秒） |
| `divExactRatio` | 除法整除比例（0.85 = 85%） |
| `basePoints` | 挑战模式答对基础分 |
| `streakBonusStep` | 连击每 +1 额外加分 |
| `correctDelay` / `wrongDelay` | 答对/答错后停留时间（毫秒） |
| `scrollDrillCount` / `scrollTestCount` / `scrollTestPass` | 秘籍演练题数 / 考验题数 / 通过线（5 / 8 / 7） |
| `scrollTestSecs` / `scrollHintDelay` | 考验每题限时（秒）/ 答错分步提示停留（毫秒） |
| `chase.lag` | 闯关追逐：怪兽初始落后距离（0.30） |
| `chase.wrongStep` | 每答错一题怪兽额外前进（0.045） |
| `chase.secPerQ` / `bossSecPerQ` | 怪兽速度按每题期望耗时（秒）标定，越小怪兽越快 |

```
math-game/
├── index.html                  # 大孩子版页面结构与无障碍语义

├── kids.css                    # 幼儿版样式（大图案、大按钮、粉嫩柔和）

└── tests/kids.test.mjs         # 幼儿版出题器与存档校验检查
```

## 回归检查

项目不需要安装依赖。修改代码后运行：

```bash
node tests/review-fixes.test.mjs
node tests/scrolls.test.mjs
node tests/kids.test.mjs
```

检查覆盖 JavaScript 语法、四类出题器的数值约束、闯关题量边界、异步取消保护、挑战截止时间保护、无障碍标记以及 Service Worker 缓存规则；`scrolls.test.mjs` 另外验证 8 个秘籍出题器生成的题目必然符合对应技巧特征（3000 轮不变量）与秘籍存档的连续性校验；`kids.test.mjs` 验证幼儿版六个活动出题器的数值范围（含「剩 0」边界）、选项生成的唯一性与幼儿存档校验，并守卫两版代码互不混杂。
